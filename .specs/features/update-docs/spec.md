# Feature Spec: Revitalização da Documentação CRM

**Status:** Draft
**Prioridade:** Alta
**Resumo:** Atualização completa da documentação do CRM para cobrir todas as funcionalidades atuais, com foco em facilidade de uso e clareza.

## Requisitos Funcionais
- Navegação lateral intuitiva.
- Busca ou links rápidos por ID.
- Passo a passo detalhado para cada funcionalidade do CRM.
- Seção técnica para integradores e desenvolvedores.
- Seção administrativa para agências.

## Requisitos Não Funcionais
- Linguagem simples, acessível para usuários não técnicos.
- Design responsivo (mobile first).
- Identidade visual Unum People (Azul, Laranja, Roxo).
- Carregamento rápido (estático).

## Mapeamento de Funcionalidades vs. Documentação
| Funcionalidade CRM | Status Atual | Ação Necessária |
| :--- | :--- | :--- |
| Login / Onboarding | Não existe | Criar guia completo |
| Kanban / Leads | Básico | Detalhar edição, filtros e inatividade |
| Vendas / Faturamento | Básico | Adicionar passo a passo de registro |
| Google Ads | Básico | Explicar benefícios e fluxo OAuth |
| Multi-Tenancy | Não existe | Criar guia para agências |
| Configurações / LGPD | Não existe | Criar guia de privacidade |
