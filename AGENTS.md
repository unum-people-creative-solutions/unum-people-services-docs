# Unum People Services Docs - Guia do Agente

Este arquivo contém as diretrizes para manutenção da Central de Ajuda e Documentação da Unum People.

## 🎯 Contexto do Projeto
Portal de suporte para usuários (inquilinos) e documentação técnica para desenvolvedores que utilizam a API de Ingestão.

## 🏗️ Estrutura de Documentação
- **Guias de Uso**: Instruções sobre como operar o Kanban e integrar o Google Ads.
- **API Reference**: Documentação OpenAPI (Swagger) para os endpoints de ingestão e CRM.
- **Tutoriais**: Passo a passo para captura de GCLID e configuração de formulários.

## 🛠️ Padrões de Manutenção
- **Clareza**: Utilizar linguagem acessível para usuários finais e técnica para desenvolvedores.
- **Sincronização**: Sempre atualizar a documentação quando houver mudanças nos endpoints da API ou novas funcionalidades no CRM.
- **Formatação**: Markdown limpo com exemplos de código funcionais.

## 📝 Comandos Úteis
- `npm run dev`: Visualizar documentação localmente (se aplicável).
- `npm run build`: Gerar site estático da documentação.
